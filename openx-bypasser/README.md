# OpenX Bypasser

A userscript for `content.openx.xyz`. It adds a small panel that lets you download available videos in 480p, 720p, or 1080p.

Install a userscript manager such as Tampermonkey, then add `openx_downloader.user.js` as a new script. Open an OpenX video page and use the panel in the top-right corner.

The download links are single-use and expire after a few minutes.

# How to user

Use this script with [Tampermonkey](https://www.tampermonkey.net/) or anything that can run Userscript.
